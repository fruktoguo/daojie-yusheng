# 道友系统

道友系统是低频社交玩法，关系真源写入数据库，不进入地图 tick 热路径。

## 关系层级

| 层级 | 说明 |
|----|----|
| 道友 | 普通双向关系，可私聊，可用于宝库权限范围 |
| 至交 | 道友的更高层级，可单独用于宝库权限范围 |

## 申请流程

1. 玩家在道友面板刷新附近候选。
2. 服务端只返回同地图实例、距离 8 格内的候选玩家。
3. 玩家向附近候选发送道友申请。
4. 目标玩家同意后，双方建立道友关系；拒绝则申请关闭。
5. 申请有效期为 7 天，过期申请不再显示。

重复申请、向自己申请、向非附近玩家申请、向已有关系玩家申请都会被服务端拒绝。

## 道友面板

道友面板顶部按以下四个子 Tab 分区，同一时间只展示当前分区：

- 「道友」：已建立的道友/至交列表及关系管理
- 「申请」：收到的申请与发出的申请
- 「附近」：附近可申请玩家
- 「私聊」：道友会话列表与单个道友的对话区

私聊为点对点即时消息，只允许已建立道友或至交关系的双方发送。收到的新消息在当前对话不可见时，会累加到「私聊」子 Tab 和对应道友的未读角标；进入私聊或点开该道友后清除该会话角标。当前私聊消息和未读状态都不作为离线邮件保存，刷新或重新登录后不会恢复。

## 与宝库权限的关系

宝库权限范围中的「道友」匹配道友或至交；「至交」只匹配至交。宝库权限仍由宝库创建者配置，最终裁定在服务端执行。
